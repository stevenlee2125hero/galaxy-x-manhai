# Security

- Never commit passwords, API keys, session tokens, copyrighted archives, or private source URLs.
- Keep the deployment and repository private unless all included content is cleared for redistribution.
- The in-app admin label is only a profile name. Real access control is provided by the private hosting layer.
- Imported files remain device-local in the current release.
- Only add content feeds you own or have explicit permission to download and translate.
